## What are Large Language Models?

Large Language Models (LLMs) are large neural networks trained on huge amounts of text to predict the next token in a sequence.

Key points:

- Dominant architecture: **Transformer**
- Training has two stages: `pre-training` and `fine-tuning`
- Example code (always shown left-to-right):

```python
def next_token(prompt):
    return model.predict(prompt)
```
